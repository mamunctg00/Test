# M Corporation Steel Cutting Calculator v6

- Responsive M Corporation interface.
- Header calculator button opens a centered calculator popup.
- Popup has a top-corner X close button, backdrop close and Escape-key close.
- Numeric input fields default to 0; text entry fields remain empty with a 0 hint until entered.
- Cutting, steel weight, price estimate and normal calculator sections included.

Upload the contents of this ZIP to the root of a GitHub Pages test repository. Do not upload the ZIP file itself.


Version 7 update: Steel Weight Calculator dimensions now have individual unit selectors beside each input (mm, inch, meter, feet). Each dimension is converted to millimetres independently before theoretical weight calculations.
