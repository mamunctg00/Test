# M Corporation Steel Calculator v8

Responsive Steel Cutting, Steel Weight and Price Estimate app.

Features: dashboard shortcuts, required cut length units (MM/inch/meter/feet), stock beam quantities and cutting quantity, theoretical steel weight with independent units per dimension and length, transfer weight/rate to Price Estimate, manual estimate weight/rate inputs, Copy Calculation chooser, Normal Calculator popup, and WhatsApp message preview.

Upload the contents of this package to the root of a GitHub Pages test repository. Do not upload the ZIP itself. Test all calculations in a browser before replacing the production site.
