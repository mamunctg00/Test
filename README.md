# M Corporation Steel Calculator v9

Reference-inspired responsive interface update. Includes home dashboard with steel-stock banner illustration, improved cutting page section navigation, steel profile illustrations, and a classic estimate-pad PNG preview. The estimate image can be downloaded or shared through the mobile system share sheet where supported.

## Deploy to GitHub Pages
Upload the contents of this ZIP to the repository root, preserving `manifest.json`, `sw.js`, `.nojekyll`, and `icons/`. `index.html` contains the page styles and application JavaScript.

## Testing note
ZIP integrity and JavaScript syntax should be checked before deployment. This package has not been exhaustively browser-tested on every device; use a test repository first and verify calculations against known steel weights before commercial use.
